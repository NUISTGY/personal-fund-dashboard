# 金融看板

## 项目功能概述

本项目为基金组合与海外市场行情看板，提供基金自选、历史净值、股票持仓、投资记录、纳指100指数趋势、纳指100期货、VXN、VIX 与七姐妹行情展示。桌面端使用 Vite 本地服务运行，Android 端使用 Capacitor 原生容器封装。

行情模块采用国内接口优先策略：纳指100指数、纳指100期货与七姐妹最新行情读取东方财富，纳指100指数分钟趋势同步东方财富交易时段数据；VXN、VIX 保留海外接口兜底。单次刷新失败时保留最近有效数据，避免趋势图或行情卡被清空。

## 环境依赖清单

- Node.js 18 或更高版本
- npm 10 或更高版本
- 现代浏览器，需支持 ES Module、Canvas 与现代 CSS
- Android 重新构建需要 JDK 21、Android SDK 34、Build Tools 34.0.0
- 网络环境需允许访问公开基金及行情接口

## 桌面端部署执行步骤

1. 安装依赖：

```bash
npm install
```

2. 启动开发服务：

```bash
npm run dev
```

3. 构建生产资源：

```bash
npm run build
```

4. 本地预览生产资源：

```bash
npm run preview
```

5. macOS 环境可双击 `./启动金融看板.app`，启动器固定使用 `5176` 端口并自动打开浏览器。

## Android APK 安装与构建

### 安装方法

1. 将 `./deliverables/金融看板-v1.0.6.apk` 传输至 Android 设备。
2. 在系统设置中允许当前文件管理器安装未知来源应用。
3. 点击 APK 完成安装或覆盖升级。
4. 应用最低支持 Android 5.1，对应 API 22。

### 重新构建

```bash
npm run build:android
npm run android:apk
```

Gradle 原始输出位于 `./android/app/build/outputs/apk/release/app-release.apk`。

发布 APK 使用项目独立的 3072 位 RSA 证书签名。`./android/signing` 中的密钥和签名配置用于后续同包名升级，需作为私密交付资料备份，禁止上传公开仓库。

## 功能使用方法

- 自选基金区域支持搜索、添加、删除和切换基金。
- 基金趋势支持 `1月`、`3月`、`6月`、`12月` 区间及净值、收益模式切换。
- 股票持仓区域展示实时价格、占净值比例、持仓市值、舆情和涨跌幅。
- 纳指100指数与纳指100期货行情每 8 秒读取最新价格；纳指100走势图支持日、周、月、年、五年区间，切换后按区间首尾价格重算涨跌幅。
- 纳指100期货与七姐妹行情每 8 秒刷新，价格跳变使用红涨绿跌反馈。
- 顶部“本次”时间表示本地请求完成时间；趋势图底部“数据”时间表示行情源实际时间。
- 手机竖屏下，纳指100期货与七姐妹采用两列四行对称布局，VXN 与 VIX 采用左右双仪表布局。
- 投资记录支持买入、卖出、净值匹配、收益统计和分析包复制。

## 数据说明

- 纳指100指数、纳指100期货与七姐妹优先读取东方财富国内行情接口。
- 纳指100指数日内分钟趋势读取东方财富 `100.NDX` 指数行情；周、月、年、五年区间读取 Yahoo 历史图表数据。
- VXN、VIX 使用海外接口兜底；接口不可用时保留最近有效数据。
- Android 通过 Capacitor HTTP 直接读取 HTTPS 行情，不依赖桌面端本地代理。
- Android 自选基金和投资记录使用设备本地存储。
- 公开行情可能存在数据源延迟，界面分别展示请求完成时间和实际数据时间。

## 需求对齐自校验

- 时间一致性：请求完成时间已改为当前设备本地时间，行情数据时间独立展示。
- 趋势连续性：刷新失败不再清空旧数据，纳指100指数报价按时间戳去重后合并进趋势序列。
- 国内接口：纳指100指数、纳指100期货、七姐妹及纳指100指数分钟趋势已切换为东方财富优先。
- 刷新频率：国内行情稳定保持 8 秒轮询；VXN、VIX 降低请求频率以避免海外接口阻塞主行情。
- Android 数据：原生 HTTP 已启用，国内行情不依赖 Yahoo 或桌面代理。
- Android UI：主图横轴标签启用自动避让，持仓卡采用紧凑三行网格，竖屏行情卡与仪表保持对称。
- APK 专用布局：基金列表、股票持仓、收益回撤指标与图表纵向占用已压缩；默认 Web 布局保持不变。
- APK 持仓布局：股票持仓压缩为两行信息网格，实时联动行情八块统一字号并缩小上下间距。
- APK 功能裁剪：原生端不加载、不展示投资记录入口与弹窗，Web 端投资记录保持原样。
- 波动率数据：APK 端 VXN、VIX 增加 Cboe 官方日线收盘数据回退，Yahoo 不可访问时仍可显示最近有效收盘。
- 应用图标：Android 启动图标更新为深色磨砂背景与简约折线图形。
- APK 纳指图：隐藏纵坐标文字并压缩左右边距，扩大移动端趋势图有效绘制宽度。
- APK 持仓列表：隐藏持仓市值与舆情，名称、实时股价、占净值和涨跌幅压缩为单行展示。
- APK 滚动优化：保留毛玻璃、渐变、高光、边框与实时价格红绿跳动反馈，仅取消外部凸起阴影；持仓采用 3 秒轮询、离屏渲染裁剪，图表区域支持直接纵向滑动。
- APK 净值区：涨跌幅移动至单位净值右侧，减少顶部纵向占用。
- APK 波动率仪表：缩小仪表半径并下移中心点，修复窄屏顶部刻度与数值裁切。
- APK 持仓状态：覆盖率文字缩小并禁止换行；下跌股票序号框同步使用绿色。
- Web 仪表盘 UI：右侧 VXN/VIX 仪表限制宽屏半径与容器溢出，扩展 Yahoo 代理超时并保留波动率回退值，避免仪表空值和刻度贴边错乱。
- Web 联动行情：纳指100期货卡片价格改为自适应字号，代码标签保留最小宽度，避免窄列下价格和 `NQ=F` 被裁切。
- Web 纳指走势图：新增日、周、月、年、五年区间切换；日内使用东方财富分钟线，周/月/年/五年使用东方财富 NDX 日线，区间涨跌幅按当前区间首尾价格重新计算；叠加 MA200 浅黄色线与偏离率浅灰色线，并过滤备用历史源与实时价明显不一致的异常序列。
- 中文乱码：页面、配置与说明文件统一使用 UTF-8，字体栈包含中文字体。
- 相对路径：代码和说明文档中的项目文件引用均采用项目目录相对路径。
- 构建交付：Web 生产构建、Android Release 构建、APK 签名、Manifest 与 SHA-256 均需在交付前重新校验。

## 已知限制与替代方案

- VXN 与 VIX 暂无稳定的国内免费实时指数接口，继续使用海外接口并保留最近有效值。替代方案为接入付费行情服务或自建境外行情代理。
- 东方财富纳指100指数分钟接口主要覆盖当前交易时段；海外接口可用时补充最近 24 小时历史，海外接口不可用时展示当前交易时段的连续趋势。
- 当前构建环境未连接 Android 实机，APK 可完成编译、签名和结构校验；最终设备兼容性需在目标 Android 设备执行安装验收。
